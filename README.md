\# Project Bot — Crypto Screener Platform



\## 📌 Описание проекта

Project Bot — это платформа Telegram-ботов для трейдеров,  

предоставляющая автоматические скринеры рынка, уведомления и аналитику.



Проект построен с прицелом на:

\- масштабирование

\- платные подписки

\- несколько бирж

\- несколько типов скринеров



---



\## 🤖 Архитектура ботов



В проекте используется \*\*несколько Telegram-ботов\*\*:



\### 🔧 Admin Bot

Назначение:

\- управление пользователями

\- управление подписками

\- администрирование скринеров

\- реферальная статистика



Доступ:

\- только владелец проекта



\### 👤 User Bot

Назначение:

\- точка входа пользователей

\- реферальная система

\- (в будущем) доступ к скринерам и настройкам
